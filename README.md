# ✅ React To-Do App

Aplicación web de gestión de tareas construida con React. Permite crear, completar y eliminar tareas, con persistencia de datos en el navegador mediante localStorage.

## 🚀 Tecnologías

- [React 18](https://reactjs.org/)
- JavaScript (ES6+)
- CSS3
- localStorage API

## 📦 Instalación

Asegúrate de tener [Node.js](https://nodejs.org/) instalado (v16 o superior).
```bash
# Clona el repositorio
git clone https://github.com/tu-usuario/react-todo-app.git

# Entra en el directorio
cd react-todo-app

# Instala las dependencias
npm install
```

## ▶️ Uso
```bash
# Inicia el servidor de desarrollo
npm start
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
```bash
# Construye la versión de producción
npm run build
```

## ✨ Funcionalidades

- ➕ Añadir nuevas tareas
- ✔️ Marcar tareas como completadas
- 🗑️ Eliminar tareas
- 💾 Persistencia de datos con localStorage
- 📱 Diseño responsive
